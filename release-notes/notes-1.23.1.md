# Xion Launcher 1.23.1

## The cape locker in game, easier to browse

The **Cosmetics** tab (Right Shift → Cosmetics) now has category chips:

- **All** — everything, with the Anime set listed first
- **Anime** — the 12 hand-painted animated capes from 1.23.0
- **Animated** — every cape that moves
- **Free** — what works without Xion+
- **Xion+** — what a key unlocks

Hover a cape and the header names it, its set and whether it needs Xion+. Click to wear
it; your elytra picks up the same texture.

## Same capes, same previews

The Anime set is the same artwork as on the site: Sunrise Torii, Sakura Dusk, Autumn Fall,
Neon Rain, Moonlit Wolf, Moonlit Bamboo, Starfall, Ember Dusk, Moon Tide, Snow Lantern,
Shadow Eyes and Night Garden, eight frames each.

Nothing else changed in this build — it is the 1.23.0 release with the cape locker
reworked, so the upgrade is small.
