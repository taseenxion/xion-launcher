# Xion Launcher 1.27.1 — Your brush-X mark

## The Xion mark you chose

The brush-painted **X** with its two sparkles is now the Xion mark everywhere:

- Launcher title bar, splash screen and first-run welcome.
- Windows app/taskbar icon and the Linux application icon.
- Website, shop and store tabs, headers and player-name cards.
- The in-game Xion menu, pause menu, mod list and title screen.

The original artwork is kept at full resolution. Its transparent mark is used in the launcher so it sits naturally on the night sky, and a moonlit app tile is used wherever a square icon is needed.

## The same X beside player names

In-game name tags and the tab list now use the brush X instead of the old shield. It stays animated with **16 frames**, using a soft silver shine for free players and warm gold for **Xion+**. Sparkles and the moving highlight stay inside the same fixed glyph width, so names never shift while the badge animates.

## Unchanged

Everything from **1.27.0** remains: the eight creator-made **HD Originals** capes at 1024×512 with original frame timing and matching elytra, Xion+ access, the shop, XION AI, animated badges, the FPS/VSync fix and auto-update.

All six client targets were rebuilt. Windows installer/portable and Linux AppImage/DEB/tar.gz update files are attached to this release.
